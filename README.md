# My Money Path

A simple personal expense tracker built to keep track of daily spending, manage cash, and understand where my money goes each month.

**Live Demo:** [expenseahh.lovable.app](https://expenseahh.lovable.app)

## About the Project

My Money Path started as a personal project to make tracking everyday expenses easier. I wanted one place to record what I spend, separate cash from UPI payments, and generate monthly reports that are easy to share with my family.

## Features

* **Expense Tracking** — Record, edit, and delete expenses with categories, dates, payment methods, and notes.
* **Cash Wallet** — Track starting cash, additional cash, cash spending, and remaining balance.
* **Bank-to-Cash Transfers** — Record cash withdrawals without counting them as expenses twice.
* **Monthly Dashboard** — View total spending, daily averages, and projected monthly expenses.
* **Category Breakdown** — See where money goes through charts and spending summaries.
* **Expense History** — Search, filter, and review transactions by date, category, and payment method.
* **Monthly Reports** — Generate spending summaries with category totals and cash-versus-UPI breakdowns.
* **Budgets** — Set spending limits and monitor progress.
* **Data Management** — Export and restore expense data.
* **Responsive Interface** — Designed to work on both desktop and mobile.

## What I Learned

This project gave me an opportunity to explore how a practical application is planned and built. I focused on expense calculations, separating transfers from actual spending, organizing transactions, and designing an interface that is easy to use every day.

I also used AI-assisted development tools to help turn the idea into a working web application while learning along the way.
